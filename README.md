# ticket-viewer

An end-to-end OCR system for purchase receipts: detect text regions, read them, and extract structured data (vendor, date, total) as JSON.

The project is being built incrementally — see [Roadmap](#roadmap) for current status. So far, a **CRNN** (CNN + bidirectional LSTM) trained with **CTC Loss** on the [ICDAR2019-SROIE](https://huggingface.co/datasets/jsdnrs/ICDAR2019-SROIE) dataset recognizes text in pre-cropped word images; text detection and key information extraction are next.

## Features

- **Automated data pipeline**: downloads the dataset, crops every labeled word and cleans the text in a single step, for both the train and test splits.
- **CRNN model**: convolutional CNN + bidirectional LSTM + CTC Loss, with no need for character-level alignment.
- **Inference script** supporting a single image, multiple images, or glob patterns.

- `vocab.txt` — character vocabulary used by the model.
- `best_crnn_model.pth` — trained model weights.

## Usage

### 1. Prepare the dataset

```bash
python setup/setup.py
```

Downloads the ICDAR2019-SROIE dataset, crops every labeled word into `dataset_crops/train/` and `dataset_crops/test/`, cleans the label text, and generates `train.csv`, `test.csv` and `vocab.txt`.

### 2. Train the model

```bash
python main.py
```

Trains the CRNN on `train.csv`/`test.csv` and saves the best weights to `best_crnn_model.pth` whenever validation loss improves.

Training can be customized via CLI flags:

```bash
python main.py --epochs 50 --batch-size 32 --lr 5e-4 --device cuda --output my_model.pth
```

| Flag | Default | Description |
| --- | --- | --- |
| `--train-dir` | `dataset_crops/train` | Directory with training crops |
| `--val-dir` | `dataset_crops/test` | Directory with validation crops |
| `--train-csv` | `train.csv` | CSV with training `image_path,label` pairs |
| `--val-csv` | `test.csv` | CSV with validation `image_path,label` pairs |
| `--batch-size` | `64` | Batch size for both loaders |
| `--epochs` | `25` | Number of training epochs |
| `--lr` | `1e-3` | Learning rate for the Adam optimizer |
| `--device` | auto (`cuda` if available, else `cpu`) | Force `cuda` or `cpu` |
| `--output` | `best_crnn_model.pth` | Path to save the best model weights |

### 3. Inference

```bash
python inferencia.py --input path/to/image.png
python inferencia.py --input "dataset_crops/test/*.png" --weights best_crnn_model.pth
```

`--input` accepts a single image, multiple paths, or a glob pattern. The predictions are printed to the console and displayed in a window alongside each image.

## Model architecture

```
Image (1×32×W) → CNN (6×Conv2d + BatchNorm + ReLU, 3×MaxPool)
                → Bidirectional LSTM (3 layers, hidden=512)
                → Linear → log_softmax → CTC Loss
```

CTC Loss allows the model to be trained on variable-length sequences without manually segmenting or aligning each character to its position in the image.

## Roadmap

The CRNN recognizer currently works on pre-cropped word images. Next steps aim to turn this into a full receipt-to-structured-data pipeline:

**Text detection (segmentation)**

- [ ] U-Net-based text detector: encoder/decoder that takes a 512×512 receipt image and outputs a 512×512 heatmap of text regions
- [ ] Script to build training masks from SROIE annotations (filled boxes over a black background)
- [ ] Detector training loop (BCE / Dice loss)
- [ ] Heatmap → bounding boxes via thresholding and contour detection

**Full pipeline & key information extraction**

- [ ] `OCRSystem` class: run the detector on a full receipt image and crop each text region
- [ ] Feed the crops through the CRNN recognizer and output text ordered top-to-bottom
- [ ] `ReceiptParser`: regex-based extraction of dates and totals (near "TOTAL", `€`/`$`)
- [ ] Heuristic line grouping: associate words at similar vertical positions despite horizontal gaps
- [ ] Structured JSON output, e.g. `{"vendor": "MERCADONA", "date": "10/10/2026", "total": 24.50}`
- [ ] Validation against real-world receipt photos
