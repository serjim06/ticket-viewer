# ticket-viewer

An end-to-end OCR system for purchase receipts: detect text regions, read them, and extract structured data (vendor, date, total) as JSON.

The project is being built incrementally — see [Roadmap](#roadmap) for current status. So far, a **CRNN** (CNN + bidirectional LSTM) trained with **CTC Loss** on the [ICDAR2019-SROIE](https://huggingface.co/datasets/jsdnrs/ICDAR2019-SROIE) dataset recognizes text in pre-cropped word images. A **U-Net** text detector is in progress: its data pipeline, data loaders, architecture and training loop are written, and it has not been trained yet. Key information extraction comes after that.

## Features

- **Automated data pipeline**: downloads the dataset, crops every labeled word and cleans the text in a single step, for both the train and test splits.
- **CRNN model**: convolutional CNN + bidirectional LSTM + CTC Loss, with no need for character-level alignment.
- **U-Net text detector (work in progress)**: full-receipt images normalised to a common text scale, 3-class segmentation masks (background, box fill, box border), joint image/mask augmentations, and a training loop that tracks Dice per class.
- **Single entry points for both models**: `main.py` and `inferencia.py` take the model (`crnn` or `unet`) as a subcommand.
- **Inference script** supporting a single image, multiple images, or glob patterns: CRNN text predictions, or U-Net masks overlaid on each receipt.

Files and folders generated by the pipeline (not version-controlled, see [`.gitignore`](.gitignore)):

- `datasets/dataset_crops/` — per-word cropped images, split into `train/` and `test/`.

- `datasets/u-net/` — normalised receipt images (`train/`, `test/`) and segmentation masks for the text detector (`train_masks/`, `test_masks/`, plus `train_masks_visible/` and `test_masks_visible/` for inspection, and `train_boxes.json` / `test_boxes.json` with the ground-truth boxes).

- `best_crnn_model.pth`, `best_unet_model.pth` — trained model weights.
- `results/` — per-run training results (`results/crnn/`, `results/unet/`).

## Usage

### 1. Prepare the dataset

```bash
python models/crnn/setup.py
```

Downloads the ICDAR2019-SROIE dataset, crops every labeled word into `datasets/dataset_crops/train/` and `datasets/dataset_crops/test/`, cleans the label text, and generates `train.csv` and `test.csv` (in `datasets/dataset_crops/`) and `vocab.txt`.

To prepare the data for the U-Net text detector (work in progress):

```bash
python models/u-net/setup.py
```

Exports the full receipt images to `datasets/u-net/train/` and `datasets/u-net/test/`, normalised so text has a similar scale across the dataset: full-page A4 scans (wider than 4000 px) are first cropped to the union of their word boxes plus a 50 px margin, and then every image is resized to a width of 640 px keeping its aspect ratio. Padding to a multiple of 32 is left to the data loader. For both splits, it also builds a segmentation mask per image from the word bounding boxes, painted after resizing so the 2 px borders are kept at the final resolution: `train_masks/` and `test_masks/` hold the class-index masks used as targets (0 = background, 1 = box fill, 2 = box border), and `train_masks_visible/` and `test_masks_visible/` hold the same masks rescaled to 0/128/255 for visual inspection. The boxes themselves, in the coordinates of the exported images, are saved to `train_boxes.json` and `test_boxes.json` (file name → list of `[x_min, y_min, x_max, y_max]`) as ground truth for box-level evaluation, since overlapping boxes merge in the masks.

### 2. Train the model

`main.py` takes the model to train as a subcommand: `crnn` or `unet`.

```bash
python main.py crnn
```

Trains the CRNN on `train.csv`, holding out part of it for validation (`--split`), and saves the best weights to `best_crnn_model.pth` whenever the validation CER (Character Error Rate) improves. When training finishes, the best checkpoint is evaluated on the test split (`test.csv`), and the run's config, per-epoch metrics (loss, CER, word accuracy, LR), best epoch (lowest validation CER) and test metrics are written to a timestamped JSON in `results/crnn/`.

Training can be customized via CLI flags:

```bash
python main.py crnn --epochs 50 --batch-size 32 --lr 5e-4 --device cuda --output my_model.pth
```

| Flag | Default | Description |
| --- | --- | --- |
| `--train-dir` | `datasets/dataset_crops/train` | Directory with training crops |
| `--test-dir` | `datasets/dataset_crops/test` | Directory with test crops |
| `--train-csv` | `datasets/dataset_crops/train.csv` | CSV with training `image_path,label` pairs |
| `--test-csv` | `datasets/dataset_crops/test.csv` | CSV with test `image_path,label` pairs |
| `--split` | `0.8` | Fraction of the training set used for training; the rest is used for validation |
| `--batch-size` | `64` | Batch size for both loaders |
| `--epochs` | `25` | Number of training epochs |
| `--lr` | `1e-3` | Learning rate for the Adam optimizer |
| `--patience` | `5` | Stop training after this many epochs without validation CER improvement (`0` disables early stopping) |
| `--device` | auto (`cuda` if available, else `cpu`) | Force `cuda` or `cpu` |
| `--output` | `best_crnn_model.pth` | Path to save the best model weights |
| `--results-dir` | `results/crnn` | Directory where the training results JSON is saved |

**Starting from existing weights.** Both models accept `--init-weights <file.pth>` to initialise the model with previously saved weights (for example `best_unet_model.pth`) instead of a random initialisation. Only the weights are loaded: the optimizer, LR scheduler, early stopping and best metric start from scratch, so the first epoch always saves a checkpoint to `--output`. If both point to the same file it is overwritten after the first epoch, so use a different `--output` to keep the original. For the U-Net, `--channels` must match the value the weights were trained with.

**Pausing training.** For both models, pressing `Ctrl+C` pauses training once the current batch finishes. While paused, the model and optimizer state are moved to the CPU and the CUDA cache is emptied, so the GPU memory is freed (only the CUDA context of the process remains). From the pause you can continue (`c`), which moves everything back to the GPU and carries on from the same batch, or finish (`t`), which discards the unfinished epoch and ends training as a normal run would: the best checkpoint is evaluated on test and the results JSON is saved. If no epoch was completed, the test evaluation is skipped.

### 3. Train the text detector (work in progress)

```bash
python main.py unet
```

Trains the U-Net on `datasets/u-net/train` + `train_masks` (80/20 train/val split) with Adam and `ReduceLROnPlateau` (halves the LR after 3 epochs without validation loss improvement), saving the best weights to `best_unet_model.pth` whenever the validation selection metric improves. If `datasets/u-net/train_boxes.json` exists (`--train-boxes`), every epoch also scores the validation split box by box (`val_box_f1`, `val_box_precision`, `val_box_recall`, `val_box_merges`, `val_box_splits`, ...) and the checkpoint is chosen by the box F1, since the pixel Dice does not rank models the same way as the boxes they produce; otherwise it falls back to the mean validation Dice of the text classes (fill and border). If `datasets/u-net/test_masks/` exists (`--test-mask-dir`), the best checkpoint is evaluated on the test split (loss, pixel accuracy, Dice, Dice per text class and IoU); otherwise that step is skipped. If `datasets/u-net/test_boxes.json` also exists (`--test-boxes`), the predicted masks are turned into word boxes and scored box by box as well (`test_box_precision`, `test_box_recall`, `test_box_f1`, `test_box_mean_iou`, `test_box_merges`, `test_box_splits`, plus the raw counts), as described below. The run's config, per-epoch history, best epoch (highest validation box F1, or Dice without `train_boxes.json`) and test metrics go to a timestamped JSON in `results/unet/`. It accepts the same `--split`, `--batch-size` (default `8`), `--epochs` (default `100`), `--patience` (default `10`, on the selection metric), `--lr`, `--device`, `--output` and `--results-dir` flags, plus `--train-dir`, `--train-mask-dir`, `--test-dir`, `--test-mask-dir` and `--channels` (width of the first U-Net layer, default `32`). Two flags tackle the imbalance of the border class (about 6 % of the pixels, against 22 % for the fill and 72 % for the background): `--class-weights` sets per-class weights for the cross-entropy (background, fill, border; `1 1.8 3.4` is 1/√frequency), and `--dice-weight` adds a soft Dice loss over the text classes scaled by that weight. Both are off by default. Run `python main.py unet -h` for the full list.

```bash
python main.py unet --class-weights 1 1.8 3.4 --dice-weight 0.5
```

Box-level evaluation lives in `models/u-net/boxes.py`: `mask_to_boxes()` keeps the fill class, takes its 4-connected regions as words and grows each box by the 2 px border, and `evaluate_boxes()` matches predicted and ground-truth boxes one to one (Hungarian algorithm, IoU ≥ 0.5) to report precision, recall, F1, and the number of merged words (one box covering several) and split words (one word in several boxes). Run it on the ground-truth masks to check the post-processing itself, which is the upper bound for any model (F1 0.993 on the test split):

```bash
python models/u-net/boxes.py --masks datasets/u-net/test_masks --boxes datasets/u-net/test_boxes.json
```

The folder name `models/u-net/` contains a hyphen, so its modules cannot be imported as `models.u-net.*` with a normal `import`; `main.py` and `inferencia.py` load them with `importlib.import_module()`. What each module does:

- **Data** (`preprocess.py`): `get_unet_loaders()` builds the train, validation and test loaders from `datasets/u-net/`. Images are loaded as single-channel grayscale. Validation is a held-out part of the train split (`split`, default `0.8`).
  - *Training*: joint image/mask augmentations (small affine rotation and scale, random 512×512 crop) followed by photometric ones that only touch the image (blur, brightness/contrast). Since every crop is the same size, batches are stacked with the default collate.
  - *Validation / test*: the whole receipt with no augmentation, padded at the bottom and right to a multiple of 32 so every pooling level divides evenly. Batch size is 1 because heights differ.
  - Padded pixels are white in the image and `255` in the mask, and `255` is ignored by the loss and the metrics.
- **Training** (`train.py`): `train()` optimises `SegmentationLoss`, a cross-entropy with `ignore_index=255` and optional class weights plus an optional soft Dice loss over the text classes (also ignoring padding), and uses the same loss on validation and test. It evaluates on the validation set after every epoch, saves the weights to `best_unet_model.pth` whenever the mean validation Dice improves, and stops early after `patience` epochs without improvement. `ReduceLROnPlateau` steps once per epoch on the validation loss, and any other scheduler steps every minibatch.
- **Metrics**: `accuracy()` returns loss, pixel accuracy, Dice and IoU, plus the Dice of every class. Dice and IoU are accumulated over the whole loader per class, and the reported value is the mean of the text classes (box fill and box border), leaving out the background because it dominates the image. The returned per-epoch history includes `train_loss`, `train_acc`, `val_loss`, `val_acc`, `val_dice`, `val_dice_fill`, `val_dice_border`, `val_iou` and `lr`. `main.py` saves it with `save_results("unet", ..., best_metric="val_dice", best_mode="max")`, so the best epoch recorded in the JSON is the same one saved as the checkpoint.

### 4. Inference

```bash
python inferencia.py crnn --input path/to/crop.png
python inferencia.py crnn --input "datasets/dataset_crops/test/*.png" --weights best_crnn_model.pth
python inferencia.py unet --input "datasets/u-net/test/*.png" --weights best_unet_model.pth --channels 32
```

The model (`crnn` or `unet`) is a required first argument. `--input` accepts a single image, multiple paths, or a glob pattern. For the CRNN, the predicted text is printed to the console and displayed in a window alongside each image. For the U-Net, each receipt is processed on its own with the validation preprocessing (grayscale, padded to a multiple of 32, normalised), the padding is cropped from the output, the mask is turned into word boxes with `mask_to_boxes()`, the number of boxes and the share of pixels per class are printed, and each receipt is shown with its predicted boxes (blue) next to its predicted mask overlaid (green: fill, red: border). The images are not resized, so they should already be normalised like the ones produced by `models/u-net/setup.py` (640 px wide). `--channels` must match the value used in training.

## Model architecture

```
Image (1×32×W) → CNN (6×Conv2d + BatchNorm + ReLU, 3×MaxPool)
                → Bidirectional LSTM (3 layers, hidden=512)
                → Linear → log_softmax → CTC Loss
```

CTC Loss allows the model to be trained on variable-length sequences without manually segmenting or aligning each character to its position in the image.

The U-Net text detector (`models/u-net/unet.py`) is a standard encoder/decoder with skip connections:

```
Image (1×H×W) → DoubleConv → 5× (MaxPool + DoubleConv)       # encoder, channels C → 32C
              → 5× (Upsample + 1×1 Conv, concat skip, DoubleConv)   # decoder, 32C → C
              → 1×1 Conv → 3 classes (background, box fill, box border)
```

Each `DoubleConv` is two 3×3 convolutions with BatchNorm and ReLU. With five downsamplings, input height and width must be multiples of 32.

## Roadmap

The CRNN recognizer currently works on pre-cropped word images. Next steps aim to turn this into a full receipt-to-structured-data pipeline:

**Text detection (segmentation)**

- [x] Script to build masks from SROIE annotations (`models/u-net/setup.py`): A4 scans cropped to the receipt, images resized to 640 px wide, 3-class masks (background, box fill, box border) for both splits plus high-contrast copies for visual inspection
- [x] U-Net data loaders with joint image/mask augmentations (`models/u-net/preprocess.py`)
- [x] U-Net architecture (`models/u-net/unet.py`): encoder/decoder that takes a receipt image resized to 640 px wide (trained on 512×512 crops) and outputs a same-size 3-class map
- [x] Detector training loop (`models/u-net/train.py`): cross-entropy ignoring padding, checkpoint on validation Dice, per-class Dice tracking
- [ ] Train the U-Net and evaluate it on the test split (class weights or Dice loss if the border class does not learn)
- [ ] Heatmap → bounding boxes via thresholding and contour detection

**Full pipeline & key information extraction**

- [ ] `OCRSystem` class: run the detector on a full receipt image and crop each text region
- [ ] Feed the crops through the CRNN recognizer and output text ordered top-to-bottom
- [ ] `ReceiptParser`: regex-based extraction of dates and totals (near "TOTAL", `€`/`$`)
- [ ] Heuristic line grouping: associate words at similar vertical positions despite horizontal gaps
- [ ] Structured JSON output, e.g. `{"vendor": "MERCADONA", "date": "10/10/2026", "total": 24.50}`
- [ ] Validation against real-world receipt photos
